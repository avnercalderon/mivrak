# מברק – חדשות לפי דרישה

אפליקציית חדשות אישית: נכנסים, היא שואבת כותרות מעשרות מקורות (RSS + Google News), מאחדת כפילויות, ומציגה רשימה צפופה לפי ערוצים. שום דבר לא רץ כשלא נכנסים.

## מבנה

```
api/fetch.js      – פונקציית שרת: שואבת עד 15 פידים במקביל ומחזירה כותרות
api/discover.js   – פונקציית שרת: מוצאת פיד RSS מכתובת של אתר
public/index.html – האפליקציה עצמה (קובץ אחד)
package.json      – תלות אחת: fast-xml-parser
vercel.json       – זמן ריצה מקסימלי לפונקציות
```

## פריסה ב-Vercel (פעם אחת, כ-5 דקות)

1. צור ריפוזיטורי חדש ב-GitHub (למשל `mivrak`) והעלה אליו את כל הקבצים כפי שהם, כולל התיקיות `api` ו-`public`.
2. ב-Vercel: **Add New → Project → Import** את הריפוזיטורי.
3. בהגדרות הייבוא השאר הכול כברירת מחדל: Framework Preset = **Other**, בלי Build Command, בלי Output Directory. Vercel יזהה לבד את `public/` כקבצים סטטיים ואת `api/` כפונקציות.
4. לחץ **Deploy**. אחרי כדקה תקבל כתובת `https://mivrak-xxxx.vercel.app`.
5. פתח את הכתובת בטלפון. ב-Safari: שיתוף → **הוסף למסך הבית**, ואז זה נפתח כמו אפליקציה.

כל דחיפה (push) ל-GitHub תפרוס גרסה חדשה אוטומטית.

## שימוש

- **ערוצים** בפס העליון. מספר ליד כל ערוץ = כמה פריטים יש בו כרגע.
- **חם / חדש** – "חם" משקלל כמה מקורות מסקרים את הידיעה וכמה היא טרייה. "חדש" – לפי זמן בלבד.
- **N מקורות** – לחיצה פותחת את כל הכותרות של אותה ידיעה מהמקורות השונים.
- **נקודה כחולה** – פורסם מאז הכניסה הקודמת שלך.
- **צהוב** – כותרת שמכילה מילת מעקב (מוגדר בהגדרות).
- **מקצועי בלבד** – בערוץ תעופה, מסתיר ידיעות שאף מקור מקצועי לא מסקר.
- **רענון** – כפתור למעלה או משיכה למטה. הרשימה הקודמת מוצגת מיד מהזיכרון של המכשיר, ומתעדכנת תוך שניות.
- **הגדרות** – הוספת מקור (מדביקים כתובת, האפליקציה מוצאת את הפיד), כיבוי/מחיקה, מצב מקורות (ירוק = תקין, אדום = נכשל + הסיבה), מילות מפתח לכל ערוץ, מילות מעקב, ייצוא/ייבוא הגדרות.

## מה חשוב לדעת

- **ההגדרות נשמרות במכשיר בלבד** (localStorage). כדי להעביר לטלפון אחר או למחשב: ייצוא הגדרות → ייבוא. אין מסד נתונים ואין התחברות.
- **פידים נשברים.** אתרים משנים כתובות. מקור אדום במסך ההגדרות – בדוק את הסיבה, ואם זה עקבי מחק אותו והוסף מחדש (או הוסף אותו כחיפוש Google News).
- **Google News** משמש כמקור למספר אתרים שאין להם פיד ציבורי יציב (הארץ, כאן, N12, TheMarker, Aviation Week, FlightGlobal ועוד). הקישור מ-Google News עובר דרך הפניה שלהם ואז לאתר המקורי.
- **סיווג לערוצים** נעשה לפי המקור + מילות מפתח בכותרת. זה לא AI: יהיו פספוסים ויהיו ידיעות שנכנסות לערוץ לא נכון. עורכים את מילות המפתח בהגדרות.
- **עלות:** אפס. הכול במסגרת החינמית של Vercel ו-GitHub.
